# Project detail preview

Open http://127.0.0.1:5500/preview/project-detail/project-01.html or use index.html in this folder to try the project links.

This is an isolated editorial design preview. Project descriptions, facts, architecture, covers, screenshots, and outcomes remain placeholders. The approved main portfolio and production build are not modified by this preview.

The design uses warm neutrals with oxblood, blue, and green project accents, Instrument Serif with DM Sans, a prominent project cover, a persistent chapter index, expandable technical notes, an asymmetric gallery, and next-project navigation. The image viewer supports arrow keys, Escape, and focus restoration. Motion respects reduced-motion preferences. A small title flourish, tinted expanded notes, a contrasting architecture panel, and richer folio artwork add character to the restrained layout.

Visual reference work emphasized:
- Synchronized: expressive serif typography and project-led composition — https://synchronized.studio/
- Floema: warm neutral surfaces and generous image transitions — https://www.floema.com/en
- Lusion: large media, small navigation, and clean project presentation — https://lusion.co/
- Pangram Pangram: deliberate typographic hierarchy — https://pangrampangram.com/
